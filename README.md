## Descripción del Programa
Programa de consola desarrollado en C# que calcula el área de un triángulo, un cuadrado y un círculo, además de verificar si una persona es mayor o menor de edad. Todo se realiza mediante funciones que reciben parámetros.

## Datos de Entrada
- Base y altura del triángulo
- Lado del cuadrado
- Radio del círculo
- Edad de la persona

## Datos que Procesa
- Cálculo del área del triángulo: (base × altura) / 2
- Cálculo del área del cuadrado: lado × lado
- Cálculo del área del círculo: π × radio²
- Determinación de mayoría de edad (≥ 18 años)

## Datos de Salida
- Área del triángulo
- Área del cuadrado
- Área del círculo
- Mensaje indicando si es mayor o menor de edad
